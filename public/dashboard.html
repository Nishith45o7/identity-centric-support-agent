Integration Guide

Developer Documentation

Quickly connect Contextis into your stack.

Full API Explorer (Swagger) ↗

1. Support Chat API

POST to /v1/support/chat with your project secret key:

curl -X POST http://localhost:3000/v1/support/chat \ -H "Authorization: Bearer sk_live_..." \ -H "Content-Type: application/json" \ -d '{ "user_id": "customer_482", "message": "My invoice has an incorrect charge.", "conversation_id": "conv_demo_1" }'

2. Embeddable Widget

Add this snippet to your web frontend with your public key:

<script src="http://localhost:3000/widget.js" data-project-id="prj_..." data-public-key="pk_live_..."> </script>
